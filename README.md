# Junior Ranger

Bin sorting games for kids. Two modes, Sort the rubbish and Catch the rubbish.

## Run it
1. npm install
2. npx expo start -c
3. Scan the QR code with Expo Go. Phone and laptop must be on the same Wi-Fi.

## Where things are
- app/index.tsx is the games menu (pick a game)
- app/sort.tsx is Sort the rubbish
- app/catch.tsx is Catch the rubbish
- components/layout.ts holds the settings for merging into the main app (EMBEDDED, GAMES_MENU, routes)
- assets/items holds the 150 item pictures
- assets/theme.ts holds the colours
